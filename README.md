# CorpBot

Корпоративный Telegram-бот для небольшой команды разработки.
Помогает вести задачи, ставить дедлайны и видеть, кто чем занят —
без ухода из мессенджера, где команда и так проводит много времени.

## Зачем

Большая часть коммуникации в команде идёт в Telegram, и переключаться
на отдельный таск-трекер (Jira, Trello, Notion) — это лишний шаг,
который на практике никто не делает. В итоге задачи теряются в переписке,
а дедлайны забываются.

CorpBot решает это, живя там, где команда и так сидит. В перспективе —
основа для внутреннего инструмента стартапа или небольшого бизнеса.

## Стек

- **Язык:** Python 3.14+
- **Фреймворк бота:** aiogram 3.x
- **БД:** PostgreSQL 18+
- **ORM:** SQLAlchemy 2.x (async)
- **Миграции:** Alembic
- **Настройки:** pydantic-settings
- **Планировщик:** APScheduler (для напоминаний)
- **Управление зависимостями:** Poetry

## Архитектура

Слоистая архитектура: обработчики не знают про БД, репозитории
не знают про Telegram.

```
handlers (aiogram)  →  services (бизнес-логика)  →  repositories  →  БД
        ↓                        ↓                       ↓
   валидация ввода        правила, сценарии        SQLAlchemy-запросы
```

- **handlers** — принимают команды и callback'и от Telegram, вызывают сервисы
- **services** — бизнес-логика: «создать задачу», «назначить исполнителя»
- **repositories** — работа с БД, только SQLAlchemy-запросы
- **models** — ORM-модели (таблицы)
- **schemas** — Pydantic-схемы для передачи данных между слоями

## Запуск

### Требования

- Python 3.12+
- PostgreSQL 15+
- [Poetry](https://python-poetry.org/docs/#installation) 1.8+

### Установка

```bash
git clone <repo-url>
cd corpbot
poetry install
```

Poetry сам создаст виртуальное окружение и поставит зависимости
из `pyproject.toml` (и зафиксированные версии из `poetry.lock`).

### Настройка окружения

Скопировать `.env.example` в `.env` и заполнить:

```bash
cp .env.example .env
```

### Миграции

```bash
poetry run alembic upgrade head
```

### Запуск

```bash
poetry run python -m app.main
```

### Полезные команды

```bash
poetry shell                      # активировать venv
poetry add aiogram                # добавить зависимость
poetry add --group dev pytest     # добавить dev-зависимость
poetry remove <package>           # удалить
poetry update                     # обновить зависимости
poetry show --tree                # посмотреть дерево зависимостей
```

## Тесты

## Структура проекта

```
.
├── app/
│   ├── handlers/      # обработчики команд и callback'ов
│   ├── services/      # бизнес-логика
│   ├── repositories/  # доступ к данным
│   ├── models/        # ORM-модели SQLAlchemy
│   ├── schemas/       # Pydantic-схемы (DTO)
│   ├── config.py      # настройки (pydantic-settings)
│   └── main.py        # точка входа
├── tests/
├── migrations/        # alembic
├── .env.example
├── .gitignore
├── pyproject.toml     # зависимости + настройки poetry
├── poetry.lock        # зафиксированные версии (коммитим!)
└── README.md
```
